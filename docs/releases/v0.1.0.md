# AgentReducer 0.1.0

AgentReducer reduces reproduced failures in prompt blocks, Markdown instruction
units and initial repository file presence. The CLI composes explicit command
oracles or qualified optional agent execution, supports exact finite-horizon
repetition and reports distinct logical/trial/process/projection costs.
Atomic report/raw export is opt-in, with default no-clobber publication.

AgentReducer v0.1.0 is release-ready under an explicit human-approved v0.1-only
waiver of successful live Codex validation. Three real AMBIENT validation
attempts failed to modify the smoke fixture; root cause remains unresolved.
The agreed development/readiness scope was accepted as PROJECT_COMPLETE.

The human authorized publication to
[LukeTsengTW/agentreducer](https://github.com/LukeTsengTW/agentreducer).
The [v0.1.0 GitHub Release](https://github.com/LukeTsengTW/agentreducer/releases/tag/v0.1.0)
identifies the exact tag/commit, wheel, source archive and SHA-256 checksums.
The [readiness checklist](v0.1.0-readiness.json) is the pre-publication readiness
snapshot, with GitHub publication authorized and actual publishing recorded by
the release. PyPI publication and deployment are separate actions.

## Install and run

Download the wheel from the GitHub Release, then install it with
`python -m pip install agentreducer-0.1.0-py3-none-any.whl`.
Python 3.11 or later is required; there are no runtime dependencies.

From a source checkout, use `python -m pip install -e .`, then run
`python examples/minimal_failure/run_demo.py --format json` for a model-free
example. [CLI](../CLI.md), [reports](../REPORTS.md) and
[security boundaries](../SECURITY.md) describe inputs and interpretation.
